## How Archivarius 3000 Sits

Archivarius 3000 does not replace a one-off hunt through papers, the unlabeled archive dump, or an index of a library you do not own. It sits beside them as a named find desk for one job: which document index is live, which archive search still matches the local library you keep, and what the next librarian should read.

If two people share a PC, each keeps an Archivarius 3000 style of their own. Extra piles wait for their own title instead of crowding the live set.

A first visit should be one short archive search on documents you keep, then the same Archivarius 3000 find desk the next day. That is enough to see if the named archive search holds.

## After a Week

A week in Archivarius 3000 is not a larger hunt through papers. It is the same title, a shorter live library set, and a note that still makes sense before the next archive search. Take finished finds off the live set so the next visit starts on the find desk that is still open.

Other programs stay where they are. Archivarius 3000 only keeps the path back: desk name, document index, local library, handoff.
